This repository contains platform source and generated branding; it does not contain commercial tool binaries, Windows images, Npcap, credentials or proprietary forensic data. npm packages retain their own licenses. Debian packages are installed by the user during their local Docker build; review their notices in `/usr/share/doc` inside the worker.

Nmap has its own [Nmap Public Source License](https://nmap.org/npsl/) and [redistribution requirements](https://nmap.org/book/man-legal.html). Do not publish a bundled Nmap container, appliance or proprietary integration without establishing applicable rights. EnCase, FTK and commercial Burp editions require separate vendor licenses; they are not included in the Linux worker.

The repository owner has not selected an open-source license for the platform. Publication on GitHub alone does not grant unrestricted modification or redistribution rights. Confirm the platform license and third-party distribution conditions before a public release. No MIT/Apache/GPL grant is asserted on the owner's behalf in this delivery.
